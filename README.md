# Практическая работа №1: Знакомство с языком Си

Репозиторий содержит решения задач Практической работы №1 по дисциплине «Программирование». Все программы написаны на чистом языке **C** и проверены на операционной системе **Arch Linux**.

## 👤 Студент
* **ФИО:** Горпинич К.О.
* **Группа:** IV-622
* **Платформа разработки:** Arch Linux, Qt Creator (CMake), GCC

## 📂 Структура репозитория

Каждое задание вынесено в отдельный файл для удобства модульной сборки:
* `pw01_1.c` — Вывод команд компиляции и запуска (один `printf`).
* `pw01_2.c` — Идентификация студента с центрированием и зеркалированием строк.
* `pw01_3.c` — Вывод данных через табуляцию `\t` с контрольной суммой символов.
* `pw01_4.c` — Расчет общего количества дней эксплуатации (`int`).
* `pw01_5.c` — Вывод вектора состояния ядра реактора посимвольно.
* `pw01_6.c` — Перевод возраста в секунды с защитой от переполнения (`long long`).
* `pw01_7.c` — Имитация POST-диагностики (`void` функции).
* `pw01_8.c` — Отрисовка лесенки сигналов многократным вызовом функции `pulse()`.
* `pw01_9.c` — Каскадный вызов пользовательских функций (`phase_1` -> `phase_2`).
* `pw01_10.c` — Финальный протокол аварийной передачи данных (сетевой handshake).

## 🛠 Инструкция по сборке и запуску

Для компиляции программ необходим компилятор **GCC** (входит в мета-пакет `base-devel` в Arch Linux).

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd arch-c-labs
```

### 2. Компиляция (на примере задачи 1.5)
* **В Linux:**
  ```bash
  gcc pw01_5.c -o pw01_5
  ```
* **В Windows:**
  ```bash
  gcc pw01_5.c -o pw01_5.exe
  ```

### 3. Запуск программы
* **В Linux:**
  ```bash
  ./pw01_5
  ```
* **В Windows:**
  ```bash
  .\pw01_5.exe
  ```
